IDE INTI
--------
Project AI untuk TIMING SFX: memilih SFX dari library milik sendiri dan
meletakkannya pada timestamp yang tepat (timing visual / whisper timing),
berdasarkan detik-detik spesifik di video.

- SFX yang dipakai: SFX ASLI yang familiar di telinga manusia.
- JANGAN pakai SFX AI-generated (bukan ElevenLabs dsb).
- Database berisi DESKRIPSI MP3 SFX (mis. "aduh tunggu") supaya AI tahu
  memilah/memilih SFX yang sesuai timing.
- Deskripsi SFX DITULIS MANUSIA (user sendiri) — sentuhan emosi manusia.
  AI TIDAK boleh menebak/mendeskripsikan isi SFX (bakal halusinasi).
  AI hanya: meng-embedding-kan teks deskripsi untuk pencarian semantik.
- Verdict: BISA dibuat, bukan halusinasi. Precedent: StoryCut, Shorz,
  Ace Studio — tapi mayoritas pakai AI-generated/library mereka sendiri.
  Gap kita: library SENDIRI + deskripsi manusia + picker timing.

ALUR KERJA (user pilih: ONE-SHOT + riwayat bisa direview)
---------------------------------------------------------
Referensi: E:\project\movie2short (pipeline contoh user:
transkrip + lihat visual → manifest → FFMPEG → selesai, one-shot).

Video + optional prompt
  → 1. TRANSCRIBE  ffmpeg extract audio → engine (ONNX|audio.cpp)
                    → word-level timestamps (WAJIB word-level, bukan segment)
  → 2. VISUAL      extract frame kunci → VLM gateway (ENV) → momen visual
  → 3. MANIFEST    LLM gabung transcript + momen → "beats" (detik + konteks)
  → 4. SFX PICK    RAG: embedding cari kandidat → LLM pilih + aturan
                    kepadatan → cue list JSON {t, sfx_id, gain, lead_ms,
                    anchor, reason}
  → 5. RENDER      ffmpeg: adelay (lead offset), ducking di bawah dialog,
                    loudnorm → video.mp4 + cue_list.json
- Setiap job simpan cue list → bisa dibuka di UI, diedit (geser timing /
  ganti SFX), RE-RENDER tanpa ulang pipeline.
- API call juga ada (tidak hanya UI studio).

ATURAN TIMING (anti "telat")
----------------------------
- Impact/whoosh: mulai ~80–150ms SEBELUM anchor (human precedence),
  disesuaikan onset_ms file (anchor ke onset, bukan awal file).
- Ambience: fade di awal scene, auto-duck ~-12dB di bawah dialog.
- Budget kepadatan: default max 1 SFX / 5 detik, hanya beat tertentu
  (punchline, transisi, reveal) — supaya tidak berantakan.
- Alasan tiap cue dicatat (reason) supaya bisa diaudit.
- Lisensi SFX: pakai library sendiri / freesound CC0.

TRAP YANG DIWASPADAI
---------------------
- Kebanyakan SFX → berantakan → aturan kepadatan wajib.
- Whisper timestamp drift → word-level alignment wajib.
- "Familiar di telinga" susah diukur otomatis → tagging kategori konsisten.

- Gateway kadang balas HTTP 200 tapi body {"error":upstream_error}

  via UI). 401/402/403/404 langsung lompat model berikutnya.
- response_format / max_tokens (8192 utk model reasoning) di-drop
  otomatis kalau ditolak. VLM TIDAK dirotasi (model teks-cadangan
